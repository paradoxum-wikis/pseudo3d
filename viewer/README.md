# pseudo3d-viewer
**Viewer**, is the spritesheet viewer for the Pseudo3D toolset, it creates draggable rotation on a spritesheet placed inside a `.pseudo-3d-viewport` element.

You can find more information about it on Fandom Developers Wiki: https://dev.fandom.com/wiki/Pseudo3D

## Dependencies
As the viewer is built with Fandom's MediaWiki environment in mind, it relies on the propietary [PortableInfobox](https://community.fandom.com/wiki/Help:Infoboxes) extension to work properly.

If your wiki isn't on Fandom, you can try using a [community fork](https://www.mediawiki.org/wiki/Extension:PortableInfobox) of the extension, but I cannot guarantee that it will work as intended.
